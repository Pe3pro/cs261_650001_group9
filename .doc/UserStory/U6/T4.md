เทียบ Sequence Diagram กับโค้ดที่รวมแล้ว

| Sequence | ขั้นใน Sequence Diagram | โค้ดที่ทำ | ตรง / ไม่ตรง |
|---|---|---|---|
| 1 บันทึกอันดับ | `matching.html` → `PUT /api/applications/{id}/preferences` | `u6.js savePreferences()` → `PreferenceController.savePreferences` | ตรง |
| 1 | ตรวจสิทธิ์ / เจ้าของ / APPROVED / ALREADY_MATCHED / INVALID_PREFERENCE | `PreferenceService.savePreferences` → `AccessGuard.require`, `requireOwner`, `MatchRepository.findFirstByApplicationIdAndStatusIn`, `validate` | ตรง |
| 1 | ลบอันดับเดิม แล้วบันทึกใหม่ | `CompanyPreferenceRepository.deleteByApplicationId` → `saveAll` | ตรง |
| 2 จับคู่อัตโนมัติ | หารอบ OPEN (409 NO_OPEN_ROUND) | `MatchingService.requireOpenRound` → `MatchingRoundRepository.findFirstByStatus(OPEN)` | ตรง |
| 2 | ใบสมัคร APPROVED ที่ยังไม่มีผล เรียงตามเวลายื่น | `ApplicationRepository.findApprovedWithoutActiveMatch` | ตรง |
| 2 | ไล่อันดับ 1 → 5 ล็อกแถวตำแหน่ง กินโควตา บันทึกผล PROPOSED แล้วหยุด | `findByIdForUpdate` → `canTake` → `CompanyPosition.takeSlot` → `MatchRepository.save` → `break` | ตรง |
| 3 เปิดรอบ / ประกาศผล | รอบเดิมยังไม่จบ 409 ROUND_NOT_CLOSED · เลยกำหนดแล้วปิดรอบ ผลที่ไม่ตอบเป็น DECLINED คืนโควตา | `MatchingService.openRound` → `closeExpiredRound` | ตรง |
| 3 | ประกาศผล OPEN → ANNOUNCED แล้วแจ้งเตือนนักศึกษาทุกคนในรอบ | `MatchingService.announce` → `MatchingRound.announce` → `NotificationService.notifyMatchAnnounced` | ตรง |
| 4 ยืนยัน / สละสิทธิ์ | ดูผล (404 ถ้ายังไม่ประกาศ) | `GET /api/matches/me/summary` → `MatchingService.mySummary` → `announcedMatch` | ตรง |
| 4 | ตรวจเจ้าของ / สถานะ / เลยกำหนด · สละสิทธิ์ต้องมีเหตุผล คืนโควตา · แจ้งเจ้าหน้าที่ | `MatchingService.respond` → `Match.confirm` / `Match.decline` → `releaseSlot` → `notifyMatchResponded` | ตรง |
