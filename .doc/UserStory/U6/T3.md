| เคส | คำอธิบาย |
|---|---|
| TC1 | นักศึกษาที่ใบสมัคร `APPROVED` เห็นบริษัทที่เปิดรับพร้อมจำนวนที่ว่าง และบันทึกอันดับ 1–5 ได้ |
| TC2 | บันทึกอันดับไม่ได้ เมื่อใบสมัครยังไม่ `APPROVED` หรือมีผลจับคู่แล้ว หรือเลือก 0 / เกิน 5 อันดับ / ซ้ำ |
| TC3 | เจ้าหน้าที่เพิ่ม / แก้บริษัทและตำแหน่งพร้อมโควตาได้ · ลดโควตาต่ำกว่าจำนวนที่จับคู่แล้วไม่ได้ |
| TC4 | เจ้าหน้าที่เปิดรอบ แล้วจับคู่อัตโนมัติตามอันดับและโควตาได้ · ใบที่จับไม่ได้มีเหตุผล · จับคู่เองและยกเลิกผล (คืนโควตา) ได้ |
| TC5 | ประกาศผลรอบแล้ว นักศึกษาทุกคนในรอบได้รับแจ้งเตือน และเห็นผลทุกอันดับ |
| TC6 | นักศึกษายืนยันหรือสละสิทธิ์ (ต้องมีเหตุผล คืนโควตา) ได้ก่อน `confirmDeadline` · เลยกำหนดแล้วตอบไม่ได้ · ก่อนประกาศผลดูผลไม่ได้ |
| TC7 | ผู้ใช้ที่ไม่มีสิทธิ์ถูกปฏิเสธ: นักศึกษาเรียก API ของเจ้าหน้าที่ · ดูหรือแก้อันดับ / ผลของคนอื่น |
