# Test Cases Specification – US8 บันทึกการทำงาน (Unit Test: UI + API + DAO)

10 พ.ย. 2026 · รวม 36 กรณี (UI 12, API 12, DAO 12)

## ภาพรวมและสมมติฐาน

- ผู้ใช้ที่ล็อกอินแล้วบันทึกงานรายวัน: วันที่ (`workDate`), เวลาเริ่ม (`startTime`), เวลาสิ้นสุด (`endTime`), โปรเจกต์ (`projectId`), รายละเอียดงาน (`description`, 1–500 ตัวอักษร)
- ระบบคำนวณชั่วโมงทำงาน (`hours`) จาก startTime–endTime และห้ามช่วงเวลาซ้อนกันในวันเดียวกันของผู้ใช้คนเดียว
- ห้ามบันทึกวันที่ในอนาคต และแก้ไข/ลบได้เฉพาะรายการของตัวเอง
- API: `POST /api/worklogs`, `GET /api/worklogs?date=`, `GET /api/worklogs/{id}`, `PUT /api/worklogs/{id}`, `DELETE /api/worklogs/{id}`
- DAO คือคลาส `WorkLogDAO` ทดสอบกับฐานข้อมูลทดสอบ (H2 / SQLite in-memory); UI และ API ใช้ mock ของชั้นถัดไป

## Unit Test Cases – API (mock WorkLogDAO, ผู้ใช้ U01)

## Unit Test Cases – DAO (WorkLogDAO + test DB, reset ก่อนทุก test)

| ID | กรณีทดสอบ | Input | Expected Result |
