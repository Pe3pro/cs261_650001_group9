# Requirement – US8 บันทึกการทำงาน

## User Story

| ID | User Story |
|---|---|
| US8-a | ในฐานะ**นักศึกษา** ฉันต้องการบันทึกงานที่ทำในแต่ละวันพร้อมจำนวนชั่วโมง เพื่อเก็บหลักฐานการฝึกและไม่ต้องเขียนสมุดบันทึกด้วยมือ |
| US8-b | ในฐานะ**นักศึกษา** ฉันต้องการเห็นชั่วโมงสะสมเทียบกับชั่วโมงที่ต้องฝึกให้ครบ เพื่อวางแผนการฝึกได้ |
| US8-c | ในฐานะ**อาจารย์ที่ปรึกษา** ฉันต้องการอ่านบันทึกของนักศึกษาในที่ปรึกษาและให้ความเห็น เพื่อติดตามความก้าวหน้าระหว่างฝึก |
| US8-d | ในฐานะ**เจ้าหน้าที่** ฉันต้องการเห็นว่าใครส่งบันทึกไม่ครบหรือชั่วโมงไม่ถึง เพื่อติดตามได้ทันก่อนจบการฝึก |

## Stakeholder

| Stakeholder | ต้องการ | Pain point ตอนนี้ |
|---|---|---|
| นักศึกษา | บันทึกงานรายวัน (งานที่ทำ ชั่วโมง ปัญหา/สิ่งที่ได้เรียนรู้) แนบหลักฐาน เห็นชั่วโมงสะสม ส่งออกสมุดบันทึกได้ | เขียนสมุดด้วยมือ ไฟล์หาย นับชั่วโมงเอง ไม่รู้ว่าครบหรือยัง |
| อาจารย์ที่ปรึกษา | อ่านบันทึกของนักศึกษาในที่ปรึกษา (ต่อจาก US7) ให้ความเห็น / ขอให้แก้ไข | ได้เห็นสมุดตอนจบการฝึกครั้งเดียว ติดตามระหว่างทางไม่ได้ |
| เจ้าหน้าที่ | ดูภาพรวมการส่งบันทึกและชั่วโมงสะสมของทุกคน แจ้งเตือนคนที่ขาดส่ง กำหนดชั่วโมงขั้นต่ำ | ตรวจนับชั่วโมงจากสมุดทีละเล่ม รู้ว่าชั่วโมงไม่ครบเมื่อสายไป |
| บริษัท / พี่เลี้ยง | รับรองการทำงานโดยเซ็นใบลงเวลา นักศึกษาเป็นผู้อัปโหลด (ไม่ได้ใช้ระบบ) | — |

## สถานะบันทึกการทำงาน

| สถานะ | ความหมาย | เกิดจาก |
|---|---|---|
| DRAFT | บันทึกร่าง ยังแก้ไขได้ อาจารย์ยังไม่เห็น | UC8-1 (บันทึกร่าง) |
| SUBMITTED | ส่งแล้ว รออาจารย์ตรวจ | UC8-1 / UC8-2 |
| REVISION_REQUESTED | อาจารย์ขอให้แก้ไข | UC8-6 |
| REVIEWED | อาจารย์ตรวจแล้ว แก้ไขไม่ได้ | UC8-6 |

## Use case

| UC | ชื่อ | ผู้ทำ | เงื่อนไขก่อน | ขั้นตอนหลัก | ผลลัพธ์ |
|---|---|---|---|---|---|
| UC8-1 | บันทึกการทำงานรายวัน | นักศึกษา | สถานะการฝึก IN_PROGRESS (US7), วันที่อยู่ในช่วงฝึกและไม่เกินวันนี้, ยังไม่มีบันทึกของวันนั้น | เลือกวันที่ → กรอกงานที่ทำ ชั่วโมง (0–12) ปัญหา/สิ่งที่ได้เรียนรู้ → บันทึกร่าง หรือ ส่ง | บันทึก DRAFT หรือ SUBMITTED, ชั่วโมงสะสมอัปเดต |
| UC8-2 | แก้ไข / ลบบันทึก | นักศึกษา | บันทึก DRAFT หรือ REVISION_REQUESTED | เปิดบันทึก → แก้ไข → ส่ง (หรือ ลบ → ยืนยัน เฉพาะ DRAFT) | SUBMITTED หรือ ถูกลบ, ชั่วโมงสะสมอัปเดต |
| UC8-3 | ดูบันทึกและชั่วโมงสะสม | นักศึกษา | — | เปิดหน้าบันทึก → เลือกสัปดาห์/เดือน | บันทึกเรียงตามวันที่พร้อมสถานะ ความเห็นอาจารย์ และชั่วโมงสะสม / ชั่วโมงขั้นต่ำ |
| UC8-4 | แนบใบลงเวลา / หลักฐาน | นักศึกษา | มีบันทึกในสัปดาห์นั้น | เลือกสัปดาห์ → อัปโหลดไฟล์ (PDF/JPG ≤ 5 MB) → ยืนยัน | ไฟล์ผูกกับสัปดาห์นั้น อาจารย์และเจ้าหน้าที่เปิดดูได้ |
| UC8-5 | ดูบันทึกนักศึกษาในที่ปรึกษา | อาจารย์ที่ปรึกษา | นักศึกษาอยู่ในที่ปรึกษาของตน | เลือกนักศึกษา (จาก UC7-4) → เปิดแท็บบันทึกการทำงาน | บันทึก SUBMITTED ขึ้นไป ชั่วโมงสะสม และไฟล์แนบ |
| UC8-6 | ตรวจและให้ความเห็น | อาจารย์ที่ปรึกษา | บันทึก SUBMITTED | อ่านบันทึก → เลือก "ผ่าน" หรือ "ขอแก้ไข" → กรอกความเห็น (บังคับเมื่อขอแก้ไข) → ยืนยัน | REVIEWED หรือ REVISION_REQUESTED + แจ้งเตือนนักศึกษา |
| UC8-7 | ติดตามการส่งบันทึก | เจ้าหน้าที่ | — | กรองตามปีการศึกษา/บริษัท/ชั่วโมงไม่ถึงเกณฑ์ → เลือกนักศึกษา → ส่งแจ้งเตือน | รายชื่อพร้อมชั่วโมงสะสม จำนวนวันที่ขาดส่ง + แจ้งเตือนนักศึกษา |
| UC8-8 | ส่งออกสมุดบันทึก | นักศึกษา / เจ้าหน้าที่ | มีบันทึก REVIEWED อย่างน้อย 1 รายการ | เลือกช่วงวันที่ → กดส่งออก | ไฟล์ PDF สมุดบันทึกพร้อมสรุปชั่วโมง |
| UC8-9 | ตั้งค่าเกณฑ์บันทึก | เจ้าหน้าที่ | — | แก้ค่าผ่าน `PUT /api/staff/settings/worklog` (field `minHours`, `reminderDays`) | ชั่วโมงขั้นต่ำและรอบแจ้งเตือนมีผลกับ UC8-3 และ UC8-7 |
